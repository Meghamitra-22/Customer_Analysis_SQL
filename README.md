# Customer Shopping Behavior Analysis

An end-to-end data analytics project that analyzes customer shopping behavior using **Python, SQL, MySQL, and Power BI**. The project focuses on data cleaning, feature engineering, exploratory analysis, business-oriented SQL queries, and interactive dashboarding to uncover customer purchasing patterns and revenue trends.

---

## 📌 Project Overview

Understanding customer purchasing behavior is important for identifying revenue opportunities, customer segments, product trends, and purchasing patterns.

This project analyzes a dataset containing **3,900+ customer transactions** and follows an end-to-end analytics workflow:

```text
Raw Customer Data
       ↓
Python & Pandas
       ↓
Data Cleaning & Feature Engineering
       ↓
SQL Database
       ↓
Business Analysis using SQL
       ↓
Power BI Dashboard
       ↓
Business Insights
